# ⚽ Футбол Соло

Веб-приложение для самостоятельной тренировки с мячом: 97 упражнений и финтов, таймер с голосовыми подсказками и «тренер», который выкрикивает команды. Открывается в браузере и ставится на экран «Домой» как обычное приложение.

## Возможности

- **Библиотека из 97 упражнений** в 8 разделах: контроль мяча, набивание, дриблинг, финты, развороты, пас и приём у стенки, удары, ловкость. У каждого есть уровень сложности, пошаговая техника, совет и ссылка на видео.
- **Тренировка**: выбираешь время (10–45 мин), уровень, фокус (финты, контроль, дриблинг, удары) и что есть рядом (стенка, фишки). Приложение само собирает план.
- **Таймер** работа/отдых с кругом обратного отсчёта, свистком, сигналами за 3 секунды до конца и голосом: «Старт», «Смени ногу», «Отдых. Далее: …».
- **Режим «Тренер»**: ты ведёшь мяч, а голос в случайный момент называет финт или разворот («Ножницы!», «Кройф!», «Рывок!»). Развивает реакцию и игру с поднятой головой.
- **Прогресс**: число тренировок, минуты, серия дней подряд, рекорд по набиванию.
- Избранное, поиск, фильтры по разделам и уровню.
- Экран не гаснет во время тренировки, всё работает без интернета, данные хранятся на устройстве.

## Установка на телефон

**iPhone:** открой сайт в Safari → «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».

**Android:** Chrome → меню ⋮ → «Установить приложение».

## Публикация

Сайт выкладывается на GitHub Pages workflow-ом `.github/workflows/pages.yml` при каждом пуше в `main`.
Один раз включи Pages: **Settings → Pages → Source: GitHub Actions**. Ссылка будет вида
`https://<пользователь>.github.io/bug-free-potato/`.

Можно и без хостинга: это один файл `index.html` без зависимостей — просто открой его в браузере.
